# Avance Número 2

En el **Avance Número 2** de nuestro trabajo, se realizaron las siguientes incorporaciones:

##  Movimiento del Juego
- Se agregó el **código para el movimiento del jugador** utilizando las teclas **W, A, S, D**.  
- Cada vez que se presiona una tecla, el jugador se desplaza en la dirección correspondiente.

##  Carpeta Assets
- Se creó la carpeta llamada **Assets**.  
- Dentro de ella se encuentran las **imágenes en formato PNG**, que se usarán más adelante para la creación de:
  - Entidades  
  - Bloques  
  - Elementos del juego  

##  Pruebas del Tablero
- Se realizaron pruebas iniciales para la **creación del tablero**.  
- Estas pruebas aún **no están presentes en el repositorio de GitHub**.
